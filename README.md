# Arcade Vault

A collection of free retro arcade games playable entirely in the browser — no download, no login, no framework.

Live at **[arcade.padmajp.com](https://arcade.padmajp.com)**

## Games

| Game | Genre | Description |
|------|-------|-------------|
| [Void Breach](void-breach.html) | Space Shooter | 12 waves of enemy warships, 3 power-ups |
| [Pixel Keep](pixel-keep.html) | Tower Defense | Random-path goblin defense, 4 tower types |
| [Pixel Snake](pixel-snake.html) | Arcade | Classic snake with 8 speed levels |
| [Void Blocks](void-blocks.html) | Puzzle | Tetris-style with ghost piece, hold & combos |
| [Neon Breaker](neon-breaker.html) | Arcade | Synthwave Arkanoid with boss bricks & power-ups |
| [Mine Sweep](mine-sweep.html) | Puzzle | Minesweeper with timer and power-ups |
| [Void Drift](void-drift.html) | Physics | Newtonian Asteroids with UFO hunting |
| [Pixel Chomp](pixel-chomp.html) | Arcade | Pac-Man style with 4 unique ghost AIs |
| [Dino Dash](dino-dash.html) | Endless Runner | Jump cacti, duck pterodactyls, day/night cycle |
| [Pixel Hop](pixel-hop.html) | Arcade | Frogger revival — cross roads and ride logs |

## Tech

Pure HTML + Canvas + vanilla JavaScript. No build step, no dependencies. Open any `.html` file directly in a browser.
